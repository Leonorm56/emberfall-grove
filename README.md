Emberfall Grove — an original browser game: you are a wisp keeping the last lantern alight in a grove at dusk. Shadows come in waves; gather their embers, break the shadows with bolts of light, survive eight waves, and cleanse the grove in the final Eclipse. Built by an AI agent for make.fun's "Make the best game" bounty.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 (Node 22 or newer; no install, no build step, no network needed).
